# Sistema de Controle de Estoque em C

Projeto desenvolvido em grupo durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS), com o objetivo de praticar os conceitos básicos da linguagem C.

O Sistema de Estoque é um programa desenvolvido em linguagem C que permite cadastrar informações de cinco produtos, calcular o valor individual de cada produto em estoque e apresentar um resumo geral dos dados cadastrados.

## Funcionalidades

- Cadastro de cinco produtos.
- Registro do código, nome, preço e quantidade de cada produto.
- Cálculo do valor total de cada produto em estoque.
- Exibição dos dados cadastrados.
- Cálculo da quantidade total de itens em estoque.
- Cálculo do valor financeiro total do estoque.

## Conceitos utilizados

- Declaração e inicialização de variáveis.
- Tipos de dados: `"int", "float"` e `"char"`.
- Entrada e saída de dados com `"scanf()"` e `"printf()"`.
- Operadores aritméticos.
- Operadores de atribuição composta `("+=")`.
- Cálculos e acumulação de valores.
- Formatação de dados na saída.
- Organização e estruturação do código em C.


## Tecnologias

- Linguagem C
- VS Code / Dev-C++

## Como compilar e executar

No terminal do VS Code, com GCC instalado, compile com:

```sh
gcc Estoque.c -o Estoque.exe
```

1. Clone este repositório ou baixe os arquivos do projeto.
2. Abra o código no Visual Studio Code.
3. Compile o arquivo utilizando um compilador C, como o GCC.

**Comando para compilar:**

``gcc main.c -o estoque``

**Comando para executar no Windows:**

``.\estoque.exe``
